# Estabelecimentos

Sistema separado da JMarySystems, no mesmo padrão dos demais.

Mantém os estabelecimentos (lojas) usados pelo **Armazenados e Não Expostos**.

## Banco

Tabela `arm_lojas` (nome, código e situação).

## Permissões

Respeita o módulo `estabelecimento` do Controle de Acesso.

## Rodar localmente

```bash
python -m http.server 5500
```
